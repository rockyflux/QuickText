全局热键唤起搜索面板。拼音、首字母、缩写、正文 —— 怎么记得住怎么搜，回车贴到光标处。

  • 文本与图片条目都能贴

缩写触发

文本指令

给条目设一个缩写，在任意输入框打出触发序列，直接展开 —— 不用打开面板。

  • 适合签名、地址、固定回复
  • 支持 {变量} 模板占位符
  • 与面板搜索共用同一本地库

隐私

你的文本，只在你的电脑上。

不注册、不同步、不上传、不统计。QuickText 默认离线；检查更新与 AI 生成需你主动开启。

  • 默认不联网日常搜索与粘贴全部本机完成。
  • 可选网络仅「检查更新」与「AI 生成」会联网，可随时关掉。
  • 明文本地库数据是你文件夹里的 JSON；机密请用密码管理器。
  • 可放同步盘想跨机器同步，把库目录丢进你习惯的网盘即可。
  • 便携模式旁放 QuickText.portable，一切数据跟 exe 走。
  • 代码公开MIT 开源，每一行都能在 GitHub 上看到。
开始

三步，一分钟。

  1. 1下载并解压

    解压 zip，双击 QuickText.exe。托盘常驻，首次带示例库。

  2. 2呼出面板

    按 CtrlShift8，搜拼音或名称，回车贴到光标处。

  3. 3维护你的库

    托盘右键打开管理，增删条目；设置里改热键、主题、语言。

问答

常见问题

真的免费吗？

是的。QuickText 以 MIT 协议开源，没有付费版，没有广告，也不收集数据。

需要安装 .NET 吗？

默认下载的 win-x64.zip 自带运行时，不需要。若已安装 .NET 10 桌面运行时，可选用体积更小的 needs-dotnet10 包或裸 exe。

会上传我的内容吗？

不会。搜索与粘贴全程本机。只有你主动「检查更新」或使用「AI 生成」时才会联网。

数据存在哪？

默认在 %APPDATA%\QuickText\，条目库默认在「文档\QuickText」。便携模式则全部在 exe 旁的 Data\ 下。

怎么更新？

应用内可检查 GitHub Releases；也可到本页或 发布页 下载覆盖。

快捷键冲突了怎么办？

在设置里点一下快捷键，按下新的组合即可。

支持 Mac 或手机吗？

目前仅 Windows。Mac / 移动端暂无计划在本仓库内交付。
